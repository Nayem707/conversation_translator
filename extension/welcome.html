Live Conversation Translator

Real-time two-way translation using the browser’s Web Speech API and classic translation services. No AI/LLMs.

1. Microphone access

The translator panel runs inside the web page as an extension frame. Chrome attributes its microphone permission to the extension, and some sites never show the prompt for embedded frames, so grant it once here.

2. Where the floating button appears

By default the button is added only on Google Meet, Microsoft Teams and Zoom Web. On any other page, click the toolbar icon (or press Alt+Shift+T) to open the translator.

3. What the extension can and cannot hear

SourcePossible?How / requirement
Your microphone Yes Web Speech API SpeechRecognition. Microphone permission prompt.
Participants in Meet / Teams / Zoom Web (tab audio) Yes, Chrome 135+ chrome.tabCapture. Only after you click the toolbar icon or use the shortcut on that tab. Captured audio is replayed so you keep hearing it, then transcribed with SpeechRecognition.start(track).
System audio (other apps, Zoom/Teams desktop) Partly Screen-share picker with “Share system audio”. Windows and ChromeOS only; macOS/Linux share tab audio only.
Meeting captions shown on screen Experimental Reads captions Meet/Teams/Zoom Web render on the page. Turn on captions in the meeting first. Depends on each platform’s page structure.
Direct access to another app’s internal audio stream No Not exposed to extensions or content scripts. Content scripts cannot capture audio at all.

4. Privacy

  • Audio is never recorded or stored by the extension.
  • Chrome’s speech recognizer sends audio to Google’s speech service unless on-device recognition is available and enabled.
  • Recognised text is sent to the translation provider you choose (Google Translate, MyMemory, or your LibreTranslate server).
  • The conversation is kept in memory only, unless you turn on “Save history”. Turning it off deletes saved history.
  • A red “LIVE” badge, a red dot on the floating button and an “ON” toolbar badge show when audio is being captured.
